# Eksperimen_WebSocket_AplikasiChat

saya membangun aplikasi chat sederhana berbasis WebSocket. Eksperimen ini dilakukan dengan menggunakan:

-Node.js (backend)

-HTML/JS (frontend)

1. Buat File  di VS Code
   
a: server.js → untuk WebSocket server (Node.js)

b: index.html → untuk tampilan klien

2. Inisialisasi dan Instalasi
   
Buka terminal VS Code di folder tersebut dan jalankan:
